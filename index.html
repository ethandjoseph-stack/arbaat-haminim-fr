Comment se fait le paiement ?

Aucun paiement en ligne sur le site. Juste après la commande, les coordonnées Bit, PayBox et virement s'affichent — la commande est réservée une fois le paiement effectué.

Quand est-ce que je récupère mon set ?

Vous choisissez le créneau de retrait directement dans le formulaire de commande.

Et si le set ne me convient pas ?

Vous examinez le set à la remise, et chacune des quatre espèces peut être échangée, sans supplément, selon le stock.
